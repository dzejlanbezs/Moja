# Payment provider logos

Drop an image here and it replaces the built-in icon for that payment method — no rebuild, no restart.

| File          | Shown on                          |
| ------------- | --------------------------------- |
| `card.png`    | The "Card" option                 |
| `paypal.png`  | The "PayPal" option               |
| `cashapp.png` | The "Cash App" option             |
| `crypto.png`  | The "Crypto" option               |

`.png`, `.svg`, `.webp` and `.jpg` all work. The logo is drawn inside a 40x40 box and keeps its aspect
ratio, so a square file of about 128x128 looks best. Delete a file and its built-in icon comes back.
