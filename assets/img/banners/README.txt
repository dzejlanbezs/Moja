Lobby banner backgrounds
========================

Drop an image here to replace the background of a lobby banner. The heading,
text and button stay on top, and a dark scrim keeps them readable.

  race.jpg   the "$15,000 Weekly Race" banner
  vip.jpg    the "VIP Transfer" banner

Any of .jpg .jpeg .png .webp .avif works, and the file name is matched loosely,
so weekly-race.png or VIP.webp are fine too. Remove a file and that banner goes
back to the built-in artwork.

Recommended size 900x320 or larger, landscape.
