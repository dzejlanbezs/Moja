Sportsbook promo banners
========================

Drop your own artwork here and the Sports page picks it up on the next reload.
Use these exact file names:

  sports-bonus.jpg      "100% Sports Bonus"
  sportsbook-live.jpg   "Sportsbook is Live Now!"
  level-up.jpg          "Boost Your Level Up!"

Recommended size 1024x576 (16:9). JPG or PNG both work — if you use PNG, keep the
name ending in .jpg or change the paths in the PROMOS list at the top of
assets/js/sports.js.

While a file is missing the banner draws a matching stand-in with the same badge,
headline and subtitle, so the strip never looks broken. As soon as a real image
loads, the overlay text is hidden because the artwork already carries the words.
